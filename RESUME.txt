PIPELINE
--------
Mic -> 48k -> FIR low-pass 16k -> RMS gate (drop silence) -> 2.5s chunk
  -> socket audio_chunk -> RMS gate -> faster-whisper (beam=1, VAD)
  -> current+next line prompt -> normalize -> tracker (line) -> comparer (words)
  -> feedback emit -> Mushaf UI (green line / red wrong / orange missing / accuracy)
